# Block City Detective

A simple blocky 2D detective game where the player explores different places in a city, studies clues, and guesses the criminal from a group of suspects.

## Features

- Blocky city theme inspired by voxel-style games
- Multiple city locations
- Clue-based criminal guessing
- Score, streak, and timer system
- Hint button
- Confetti and sound effects for correct guesses
- Responsive layout for desktop and mobile

## How to Play

1. Open `index.html` in a browser.
2. Read the clues for the current city location.
3. Compare the clues with the suspects.
4. Choose who you think the criminal is.
5. Solve all cases and try to get the highest score.

## Files

- `index.html` - Main game page
- `styles.css` - Game styling and layout
- `script.js` - Game logic
